# Brainstorm Atlas

## Start the portal

1. In `backend`, copy `.env.example` to `.env`.
2. Set a unique `ADMIN_USERNAME` and a long `ADMIN_PASSWORD` in `.env`.
3. Run `npm start` from the `backend` folder.
4. Open `http://localhost:5050`.

The `.env` file is intentionally ignored by Git, so administrator credentials are not committed with the project.
